# Eissa Math Quest · رحلة عيسى في الرياضيات

A bilingual, interactive, game-like course on ratios, rates, proportions, and percentages. It is built with plain HTML, CSS, and JavaScript and works on GitHub Pages without a build step.

## Features

- 19 guided bilingual lessons with worked examples and checks for understanding
- Three real interactive labs: ratios, proportions, and percentages
- 54 verified source-based practice questions
- Flexible answer normalization for spaces, commas, currency, percent signs, ratios, and equivalent fractions
- Adaptive 10-question Memory Mode using locally stored performance
- Randomized 15-question Final Challenge with mistake review
- XP, streaks, mastery, badges, per-topic progress, and confirmed reset
- Arabic, English, and Both modes; RTL/LTR; keyboard access; reduced-motion support
- Responsive layouts for phone, tablet, and desktop

## Files

- `index.html` — semantic shell and bilingual navigation
- `styles.css` — responsive visual system, animation, accessibility, RTL/LTR
- `data.js` — lesson and question content
- `app.js` — renderers, labs, answer checking, adaptive review, progress
- `source-coverage.md` — page-by-page source audit and answer decisions

## Run locally

Open `index.html`, or serve the folder with any static web server. No API keys, login, backend, package install, or build command is required.
