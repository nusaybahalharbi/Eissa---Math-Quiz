# Eissa Math · رياضيات عيسى

A calm bilingual learning website for ratios, rates, proportions, and percentages.

## Two-page structure

1. **Lessons · شرح الدروس** — 14 child-friendly lessons with a familiar scenario, why the topic matters, one-sentence idea, visual model, explained steps, easy and harder checks, common mistake, memory trick, and embedded activity where useful.
2. **Test & Questions · الاختبار والأسئلة** — all 54 source questions, topic practice with immediate teaching feedback, and a randomized 15-question final test with mistake review.

## Accessibility and behavior

- Arabic, English, and clean bilingual modes
- Arabic RTL and English LTR
- Standard English digits `0–9` throughout
- Runtime safeguard converts accidental Arabic-Indic or Persian digits before display
- Flexible ratio, fraction, decimal, percent, currency, and spacing normalization
- Progress saved in `localStorage`
- Keyboard-friendly controls and visible focus states
- Responsive phone, tablet, and desktop layout
- Reduced-motion support

## Technical details

Plain HTML, CSS, and JavaScript. There is no backend, login, API key, package install, or build step. GitHub Pages serves the files directly from the repository root.

See `source-coverage.md` for the complete 37-page source audit and question mapping.
